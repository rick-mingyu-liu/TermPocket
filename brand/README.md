# TermPocket brand assets

**TermPocket** — *Your money, term by term.* Always one word, capital T and P,
in every language.

Everything here is generated by [`build.mjs`](build.mjs) from the geometry in
that file and the wordmark outlines in [`src/wordmark.json`](src/wordmark.json):

```bash
node brand/build.mjs      # needs Node 18+ and rsvg-convert (brew install librsvg)
open brand/preview.html   # every variant, plus the icon at 16, 24 and 32 px
```

Edit `build.mjs`, not the outputs. It also copies the files the web app serves
into `frontend/public/`.

## Files

| Path | What |
|---|---|
| `svg/termpocket-logo.svg` | Horizontal icon + wordmark, for light backgrounds |
| `svg/termpocket-logo-dark.svg` | The same, for dark backgrounds |
| `svg/termpocket-logo-mono.svg` | One ink (black) plus white, for single-colour print |
| `svg/termpocket-icon.svg` | Standalone icon (`-dark`, `-mono` variants alongside) |
| `svg/termpocket-icon-small.svg` | Simplified icon for 16–48 px: four heavier stitches, thicker loop outlines |
| `png/` | Transparent PNG exports of the above |
| `favicon/` | `favicon.ico` (16/32/48, from the small icon), `favicon.svg` (switches to the dark pocket under `prefers-color-scheme: dark`), `apple-touch-icon.png` (180, opaque), `icon-192.png`, `icon-512.png` |
| `src/wordmark.json` | Wordmark outlines and the font they came from |
| `src/LICENSE-Figtree.txt` | The wordmark font's licence (SIL OFL 1.1) |

The web app serves `frontend/public/brand/termpocket-logo{,-dark}.svg`,
`termpocket-icon{,-dark}.svg`, and the favicon set at the site root.

## How it differs from the approved references

- **Wordmark typeface.** The reference face is not identified. The wordmark is
  **Figtree** at weight 770 (OFL 1.1), the closest of 24 open-licence families
  scored letter by letter against the reference. Next were Albert Sans and
  Gabarito. Figtree's corners are sharp where the reference's are softly
  rounded. Its `c` and `e` terminals are longer and more angled, the `k` is a
  little shorter and the `t` a little taller. Its default kerning, tightened
  by 0.025 em, sets the word about 6% wider than the reference at the same cap
  height. The reference spaces "Term" looser and "Pocket" tighter than any
  regular kerning does.
- **Symmetry.** In the reference the calendar and its loops sit about 7 px
  (0.6%) right of the pocket's axis. Here they are centred.
- **Dark variant.** The deep green pocket has a contrast of 1.4:1 against the
  app's dark background (`gray-900`), so the dark variant lifts it to
  `#1E7A4E` (3.3:1). The loops stay deep green.
- **Small sizes.** At 16–48 px the eight stitches and the 15 px loop outlines
  blur together. The favicon uses four stitches and doubled outlines. The
  silhouette is unchanged.
- **Monochrome.** One ink plus white, so the icon stays opaque. Android's
  themed `android-icon-monochrome.png` is the exception: Android reads that
  layer by its alpha alone, so its details have to be cut out.

The icon's silhouette matches the reference with an IoU of 0.990 in the
reference's own pixel space.
